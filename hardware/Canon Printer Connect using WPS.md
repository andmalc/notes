On the Canon PIXMA TS3720, the Wireless Select button and the Wireless Connect button serve completely different purposes for managing your printer's network: [1, 2] 
## 1. Wireless Select Button ((p)) / 📱

* 
* What it does: It manages the active network mode directly on the printer. [2] 
* How it works: Each quick press cycles through and switches your printer's active status between Standard Wi-Fi (connecting to a router), Wireless Direct (the printer acts as its own hotspot for direct device pairing), or disabling wireless entirely. [1, 2] 
* WPS Function: Holding this button down is specifically used to trigger a hardware-to-hardware handshake with a router using a WPS button. [3] 
* 

## 2. Wireless Connect Button 🔗 (Overlapping Loops)

* 
* What it does: It puts the printer into "Easy Wireless Connect" pairing mode.
* How it works: Holding this button down for about 3 seconds makes the printer broadcast a temporary setup signal.
* App/Computer Function: Instead of interacting with your router, it allows a smartphone (via the Canon PRINT app) or a computer (via downloaded setup software) to securely "find" the printer and pass your home Wi-Fi name and password directly over to it. [1, 4, 5, 6, 7] 
* 

## Direct Comparison

| Feature | Wireless Select Button ((p)) / 📱 | Wireless Connect Button 🔗 |
|---|---|---|
| Primary Use | Toggles modes (Wi-Fi, Direct, Off) or connects via physical Router WPS button. | Starts an automated software-guided setup. |
| Best Used For | Quick router connections without an app. | Setup via Smartphones, Tablets, or Computers. |
| Action | Short press to cycle modes; Long press for router WPS sync. | Long press (3 seconds) to trigger app-pairing broadcast. |
